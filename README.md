# 物记 · 网页版使用说明

「物记」是一个记录日常使用过的物品、给物品打分、并查看社区真实使用评价的网页应用。当前版本为第一版（演示版），数据只保存在你打开它的这台设备的浏览器里，不会上传到任何服务器。

## 怎么打开

**最简单的方式**：直接用浏览器打开 `index.html` 文件（双击即可）。

**想用手机访问**：把这个文件夹放到任意网站服务器上（或者使用本机的局域网/公共通道），手机打开后可以添加到主屏幕当 App 用。

任选一种方式：

- 直接双击 `index.html` 用浏览器打开；
- 在项目文件夹打开命令行，运行 `python -m http.server 8000`，然后浏览器访问 `http://localhost:8000`；
- 或者把整个文件夹放到任意网站服务器上，手机也能访问。

## 目前有的功能

- 记录物品：扫码自动带出商品信息（查不到就手动补，扫过的物品会记住）；也可以直接手动填写；品类两级点选；购买途径点选（先选线上/线下，再选具体渠道）；填写购买价格；1-5 星打分；选择是否会回购；写一句短评；表单底部可以拍张照或从相册选一张照片
- 个人时间线：首页看到最近的记录和本月概览
- 我的物品：按物品分组查看，可点“再买一次”继续添加同一物品的购买记录，并统计已买次数
- 商品详情：自己的记录信息；照片可点击全屏查看
- 月度复盘：本月最佳、本月踩雷、品类分布、记录天数、本月花费
- 我的：改昵称、导出数据（JSON）、恢复演示数据、清空记录

## 说明与下一步

- 社区评价功能暂时下线，后续需要时再接真实服务。
- 扫码依赖浏览器能力：安卓 Chrome 原生支持条码识别；iPhone 的 Safari 会自动加载内置识别组件（需要联网）；商品信息优先来自国内商品库（极数本源条码查询，覆盖农夫山泉等快消品，返回名称、品牌、规格、价格和图片），查不到时自动回退到国际开放商品库 Open Food Facts，再不行可手动补充，扫过并保存过的物品会永久记住。免费接口每天约 20 次（匿名）/ 200 次（注册），超过后会自动走备用库，不影响使用。
- 相机功能必须走加密地址（https）才能使用，局域网 http 地址下扫码会不可用。
- 下一步可以做的：把 App 免费部署到网上（手机浏览器访问、可添加到主屏幕当 App 用）、接入真实商品库、加后端让社区评价真正长出来。
